# Plenary(設備手帖)

建築設備エンジニア向けの計算ツール集。単一HTMLファイルで動作するブラウザベースのPWAです。

**🔗 Live Demo**: https://meyonze.github.io/Plenary/

## 特徴

- インストール不要・登録不要。ブラウザで開くだけで動作
- 単一HTMLファイル完結(外部依存なし)
- PWA対応でオフライン動作も可能
- JIS・SHASE・JEAC・ASHRAE等の規格をベースにした計算式

## 収録ツール

### 設備計算(EQ)
| No. | ツール名 |
|---|---|
| EQ-01 | ダクトサイズ計算 |
| EQ-02 | ダクト圧損(直管・局部) |
| EQ-03 | 換気量計算 |
| EQ-04 | 吹出・吸込口計算 |
| EQ-05 | 空気線図 |
| EQ-06 | 負荷計算(簡易) |
| EQ-07 | 水配管 |
| EQ-08 | 排水勾配 |
| EQ-09 | 吊り支持・振れ止め |
| EQ-10 | 風速・動圧・圧力損失変換 |
| EQ-11 | 保温材計算 |
| EQ-12 | 電線・ブレーカー選定 |

### 資料(RF)
| No. | ツール名 |
|---|---|
| RF-01 | 鋼材・ボルト |
| RF-02 | 単位換算 |

### 音響計算(AC)
| No. | ツール名 | 提供 |
|---|---|---|
| AC-01 | 屋外騒音(距離・回折減衰) | 無料版:基本計算 / Pro版:オクターブバンド・回折減衰・指向係数Q選択 |
| AC-02 | 騒音合成 | 無料版:基本計算 / Pro版:オクターブバンド・複数音源ストック |
| AC-03 | NC判定 | 無料 |
| AC-04 | SPL↔PWL変換 | 無料版:単一値変換 / Pro版:1/1オクターブバンド変換 |
| AC-05 | 消音チャンバ | 無料 |
| AC-06 | 透過損失 | 無料 |

## Pro版について

音響計算の一部機能(オクターブバンド計算、回折減衰、複数音源合成など)とウォーターマークなし印刷は、ライセンスキーによる買い切り課金制です。キーはnote記事にて配布しています。

## 開発方針

- 「参考値」としての設計思想:断定的な推奨値ではなく、検討の足がかりとなる情報を提供する
- データの正確性には注意を払っていますが、実務での最終判断・照査は利用者ご自身の責任でお願いします

## Tech Stack

- Vanilla JS / HTML / CSS(フレームワーク不使用)
- 単一ファイル構成
- LocalStorage(設定・ライセンス保持)
- Web App Manifest(PWA)
